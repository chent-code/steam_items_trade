## 1. 你的策略的正确形式（接受你的 UUYP 闭环反驳）

### 1.1 恒等式

你的做法在 UUYP 上是一个**单平台闭环的余额搬砖**：

```
买入（消耗 UUYP 余额）→ 持有 7 天 → 卖出（获得 UUYP 余额）
净 P&L = [平台价(t+7) − 平台价(t)] / 平台价(t) − 提现费 1% − 资金时间成本
```

经典倒余额是跨平台的（人民币 → BUFF 买 → Steam 卖 → 得 Steam 余额，靠余额折价变现）；**你把它压缩成了单平台闭环**，这一步比你可能意识到的更激进：

- 悠悠有品 **CS 交易服务费 0%**，提现 1%（BUFF 出售手续费 1.5% + 提现 1%；IGXE 0.6% + 0.8%；C5 1%；Steam 市场约 15% = 5% Steam + 10% CS2 发行商分成）
- 如果余额在平台内循环使用（买→卖→再买），**提现费也永远不发生**
- 于是你的摩擦只剩：7 天锁定期 + 价格波动 + 资金时间成本

**这是一条零手续费、零提现费的闭环路径。** v1 建议你去查 Steam 求购价是错的方向，你不用。

### 1.2 但闭环里没有"落袋"

这是你需要给这笔钱命名的准确方式：**在闭环里，你赚到的 10% 是"余额形态的转换"，不是"兑现"。** 你把 ¥100 余额换成了价值 ¥110 的另一个余额。真正变现只有两条路：① 提现（1%）；② 停止循环、开始净提现。

这条不改变策略好坏，但改变**你该盯什么指标**：闭环策略的收益是**余额的账面增长**，而"账面增长"和"可提取净额"之间还差一层。这一层在市况好的时候无所谓，在市况崩的时候会让你在最差的时点被迫变现。

### 1.3 一个此前没提的、对你有利的推论

**如果你的收益来源是价差收敛而不是方向，那么这个策略在"平且波动大"的市场里最好，而不是在上涨市场里最好。**

第 42 周正是这个环境：目录估值 −0.89%，但涨幅前六 +42.7%~+101.5%、跌幅前六 −54.9%~−65.9%。**中位数持平 + 极端分散 = 收敛交易的最佳土壤**，因为收敛要的就是"起点和终点之间的位移大"，而不在乎位移的方向。

这解释了你说的"大盘持平但我这批全涨"——**如果它是纯 beta，你的品种不该在持平的市场里全涨；如果它是收敛，在持平的市场里全涨恰恰是应有之义。**

可证伪的预测：**你的策略收益应当与市场方向弱相关甚至负相关，与市场内波动率、横截面离散度正相关。** 如果跑 8-12 周后发现收益与大盘同涨同跌，那说明你赚的是 beta 不是价差，逻辑要重写。

## 2. 撤回 ζ 之后：更精确的版本是"入场价是尾部订单统计量"

### 2.1 为什么你反驳得对

v1 的机制是"你的买量改变了显示价"。你说得对：一周几百笔交易，订单簿换了不知道多少轮，终点那一档不可能留着你那 1 件的痕迹。**这个版本撤回。**

### 2.2 但你的选品规则取的是两个极值

你的判据是 **平台售价 ÷ Steam 最高求购价 最低**。注意两端：

- **分子（平台售价）= 卖方报价的最小值（min over asks）**
- **分母（Steam 求购价）= 买方报价的最大值（max over bids）**

**两端都是极值统计量。** 而"这一周之后再看价格"这个动作，你读到的仍然是**另一个时点的 min over asks**。

这里有一条**完全不需要你的买量有任何影响**的路径：

> 你按"折扣最低"扫出来的那一档，恰好是订单簿上**异常低的一档**（卖家睡着了 / 挂了很久没动 / 刚被脚本挂上去 / 一个不懂行的卖家）。你 1-2 件就把它吃掉了。一周后那一档早已被填平，新的最低在售价回到**市场清算价**。
>
> **你观察到的 "+10%" = 你的入场价是个尾部离群值，而不是市场涨了 10%。**

### 2.3 关键区别：这条路仍然不是"假象"，但它改变了收益的性质

要分清两件事：

- **ζ-v1（错）**：我的买量推高了价格 → 你的收益是假的
- **ζ-v2（本节）**：我买在了一个离群的低价档 → **你的收益是真的**（你确实用远低于市价的价格拿到了货，而且能在新价位上卖掉兑现）——但它的性质是**一次性的库存挑选收益**，不是"市场要涨"的信息

差别在可重复性：

- 如果池子里**一直有**这种深度价差的离群档位，你就一直能捡到 → 这是**流动性提供收益**，稳定但有上限（受离群挂单密度限制）
- 如果离群档位是**被你上一周的买入耗尽**的，那你下周就买不到同样的便宜 → 你的 +10% 是**自我消耗**的，用一次少一次

**这直接决定了你该怎么做**：如果不做区分，你会误以为"下周还有 10%"，然后在离群档位枯竭的周里吃个大亏。

### 2.4 判别方法（不需要任何额外交易）

- 看这批品种在 t 时刻的**完整 ask 阶梯**：你的成交档位相对该品种自身最低价阶梯中位数的位置。若你的买价比该品种自身的常态低 10%+，那是 ζ-v2（尾部入场），不是"市场要涨"。
- 看一周后**该品种的成交量加权成交价 / 中位成交价**是否也上移了 10%：
  - 上移了 → 真的涨了，你的收益更硬
  - 没上移，只有"最低在售价"上移 → ζ-v2 确认，你的收益来自入场价挑选

## 3. 你的观察到底是什么：三种解释，两种可执行路径

现在把"平台价一周涨 10%"这个观测的所有可能解释列清楚，并给出各自的判决方法。

| 解释 | 机制 | 你的收益性质 | 判决方法 |
|---|---|---|---|
| **E1 价差收敛** | 平台价向 Steam 求购价收敛 | 价差收敛，**不依赖市场方向** | 查 Steam 求购价是否同期下移（见下） |
| **E2 尾部入场** | 入场价是离群低档，市场清算后"涨"回常态 | 一次性的库存挑选收益，**用一次少一次** | 查成交量加权成交价是否同步上移 |
| **E3 方向性 alpha** | 你选的这批品种本身要涨 | 方向性预测，脆弱 | 只有排除了 E1/E2 才轮得到它 |

### 3.1 E1 与 E2 的判决：查"分母"的生死

这是本轮最重要的一条，成本极低、判决力极强。

你的信号依赖 **Steam 最高求购价**这个分母。它是"外挂信息"，不是成交价。两种截然不同的情形：

- **分母是真的**：Steam 上真的有人挂着高价收货（真套利者）
- **分母是假的**：那个最高求购单是**富报价**——挂了一个远高于市价的价格，或者根本挂不满/随时撤销

**判决动作**：查这十几个品种在 t 到 t+7 期间，**Steam 的最高求购价有没有被下掉、被成交、或被改成接近市价**。

- Steam 求购价**下移回市价**，而平台价**没涨** → **分母是假的**。你看到的"折扣最低"是幻觉，E1/E2 都不成立
- Steam 求购价**基本没变**，平台价涨了 → **分母是真的，E1 成立**：平台向一个真实存在的需求报价收敛。这是最健康的情形
- Steam 求购价**也涨了** → 整个品种在涨，你赚的是 E3

> 这一条查完，你对"十几个全涨"的解释就从三选一变成唯一解。**请优先做这个。**

### 3.2 判别 E1 的一个反直觉细节

**如果 E1 成立（价差收敛），那你的策略收益应该与"到锚的距离"成正比，而不是与"涨了多少"成正比。**

社区口径的锚：倒余额折扣率 = 平台最低价 ÷ (Steam 求购价 × 0.8696)，其中 0.8696 = 1 ÷ 1.15（Steam 手续费）。这个比例的历史常态在 **0.65–0.70** 区间（对应坊间说的"75 折"，2024 年 5 月最好时到过 76 折 = 0.661）。

所以：

- 你选品 = 在这个比值的**最低端**挑
- 一周后，这个比值应该向 **0.65–0.70 的锚**回归
- **你的利润上界 = 入场比值到锚的距离**，而不是"涨了 10%"

**判决方法**：算出 t 和 t+7 两天的比值，看它是否向锚回归。

- 比值回归到锚附近，且平台价涨了 → **E1 确认，纯收敛，你的收益上界已经摸到了**
- 平台价涨了但比值**没有**向锚回归（比值甚至更极端） → 这不是收敛，这是**方向性**，性质完全不同、更脆弱、且和"倒余额"这个名字没关系

这是把你 12 个样本变成一个可证伪命题的最短路径。

### 3.3 还有一个不该忽略的判别：分母修正后你的"最低比值"还剩多少

用 csqaq 的挂刀口径重算一遍这批品种，把 Steam 求购价替换成"前 N 档求购的加权价"（而不是最高一档），看排名是否稳定。

- 排名基本不变 → 你的选品对"外挂最高档"不敏感，信号是稳的
- 排名大幅变化 → 你之前挑中的很大程度是"Steam 上有人挂了个离谱高价"，信号是脆的

## 4. 新发现：7 天交易保护期把所有人锁进了同一个窗口

这一节是 v1 完全没有的，也是本轮最有价值的一块。

### 4.1 机制

- **2025-07-15 起**（Premier 第三个赛季），Valve 启用 CS2 **交易保护（Trade Protection）**：通过交易收到的饰品进入 **7 天保护期**，期间**不可消耗、不可修改、不可转移**（含上架市场）；保护期内交易双方可**撤销交易**，撤销方 30 天内被禁用市场与交易功能
- **2024-10-02** Armory 更新起，游戏内商城 / 社区市场购买 / 交易获得的饰品，同样有 7 天的 re-trade + re-market 限制
- BUFF 官方据此调整：**订单结算周期延长到 7 天 CD 结束后**（`buff.163.com/news/76284`）
- CS2 物品已不再有 15 天的 Steam trade hold（无手机令牌时），改为 7 天保护期 + 账号级限制

### 4.2 你的"一周"不是你选的

你在 UUYP 买入 = 通过交易获得物品 = **进入 7 天保护期，期间不可上架、不可转移**。

所以：

1. **"一周后观察"是 Valve 强制的最短持有期**，不是你选的窗口，也不是你选的信号周期
2. 更关键：**T0 买入的所有人，在 T0+7 同时解锁**
3. 于是 **T0+7 那天，同一批入场的库存同时涌向平台抛售** → 平台 ask 在那个时点被压低 → **平台/Steam 比值在那个时点被系统性压到最宽** → **"折扣最低"这个规则，系统性地挑中了这一天的品种**

### 4.3 这对你的观测意味着什么：你的 +10% 是保守估计

你在 T0+7 观察平台价，而**那个时点的 ask 正被你自己的 cohort（以及所有同策略玩家的 cohort）压低**。

- 你的成交档位（异常低的离群档）在 T0 就被吃掉了 → 起点被压低
- T0+7 的 ask 被 cohort 抛售压低 → 终点也被压低

两头都被压，但**起点压得更狠**（你的入场是尾部离群值，§2）。净效果：**你观察到的 +10% 大概率是低估的**。这是本轮唯一一个"你的观测被系统性低估而非高估"的方向，**v1 那条 ζ 论证在方向上恰好是反的**。

### 4.4 但这引出一个更有意思、也更可检验的版本

既然折扣最深的品种来自"刚被一波抛售砸过"，那你的选品可能在系统性地做一件事：

> **买刚被砸过一波的品种，等下一波流动性需求把它拉回来。**

这是一个**均值回归 / 强制供给波峰上的流动性提供**机制。它有真实的经济基础（7 天锁定期制造了周期性的强制供给，而平台上的买家是持续的），比"市场要涨"扎实得多。

**判决方法**：把每个品种在 T0 之前 7 天的价格序列拉出来，看你的选品是否系统性地处于近期低位（相对它自己的 30 日中位数）。

- 系统性处于近期低位 → 机制确认：**你赚的是"波峰后的均值回归 + 流动性提供"**
- 不是 → 回到 §3 的三分支

### 4.5 顺带：星期几入场是个免费参数

社区经验：Steam 价格周六日清晨到中午普遍最高，十二点以后到晚上偏低；下午/晚上在悠悠下单、第二天早上出货折扣率更高。加上 §4.2 的 cohort 同步，**入场星期几会同时改变你的入场价和你解锁日的市场状态**——这是个你可以单独打 A/B 的维度，8-12 周里轮换即可。

### 4.6 这也给了你一个远比"每天快照"更省事的回测设计

因为 7 天窗口是被强制的、cohort 是同步的，回测不需要处理任意起止的对齐问题：

```
对每个历史交易日 T：
    用 T 日的挂刀行情选出比值最低的 N 个品种
    记录 T+7 日的 成交价 / 最低在售价 / Steam 求购价
    算 P&L（按 §1.1 恒等式）
    减去同池同流动性分层的匹配基准
```

**数据源**（现成，不用自己爬）：
- **csqaq**：挂刀行情每 15 分钟更新，全站饰品数据 5–15 分钟全量更新；直接给出「Steam求购挂刀 = 平台最低价 / (steam求购价 × 0.869)」「Steam日成交量」「在售/求购数量」等字段，还有「饰品大盘指数」的官方计算公式
- **cs2.sh API**：`/v1/prices/latest` 给 BUFF 与 Steam 的 `ask / bid / ask_volume / bid_volume`（`ask_volume`/`bid_volume` = 挂在该价位的挂单/求购数量，**正好用来判断"最高求购"是不是只有 1 件的富报价**）；`/v1/market/steam/latest` 给完整订单簿阶梯
- **BUFF/悠悠有品挂刀插件**：Steam 求购表 + 日销量 + 折扣率，实时

## 7. 修订后的结论

1. **你的两条反驳都成立，v1 的 ζ-v1 和"收入变量在 Steam 侧"均撤回。** 你描述的 UUYP 单平台零手续费闭环是比 v1 建议更优的执行路径。

2. **你的观察大概率是真的，而且我上一版低估了它。** 因为 7 天交易保护期让你和所有同策略玩家在同一天解锁、同时抛售，T0+7 的平台价被你自己的 cohort 压低；而你的入场价本身是尾部离群档。**两头都被压、起点压得更狠 → 你的 +10% 是保守估计。**

3. **但你描述的机制（"预测一周涨跌"）和实际在赚的钱（价差收敛）不是同一件事。** 收敛型收益不依赖市场上涨——它依赖"起点到锚的距离"。这既解释了大盘持平时为何全涨，也意味着**你现在真正该盯的不是涨没涨，是折扣比值有没有向 0.65–0.70 的锚收敛**。上限是摸到了的。

4. **最需要警惕的不是运气，是"分母是假的"。** 你的信号整个挂在 Steam 最高求购价上，而它可能是一个挂不满、随时撤销、远高于市价的富报价。这条查完，你的"十几个全涨"就从三选一变成唯一解。**请先做测试 1。**

5. **"期望为正"仍然需要 8–12 周的完整日志来证。** 现在你手上只有一次观测。不过——如果测试 1、2、3 全部通过（分母真实、比值向锚回归、成交价同步上移），那这不再是一个"运气很好的样本"，而是一个**有机制、有边界、可复测的价差收敛策略**，只是别再叫它"预测涨跌"。
